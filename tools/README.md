# 维护与诊断工具

当前运维入口：[运维手册](../运维.md)。默认回归和浏览器验收在 `../scripts/` 与 `../test/`，不需要调用真实模型。

| 位置 | 用途 |
| --- | --- |
| `check_static.py` / `check_locks.py` | 静态检查与锁调用诊断；历史规则需结合当前源码判断 |
| `dbq.py` | 数据库查询工具，包含会写入的通用入口；先看参数说明，不对正式库试写 |
| `browser_verify.js` / `browser_stream.js` | 旧 CDP 验证工具；可能发送真实消息或关闭服务，不作为默认冒烟 |
| `conv_feed.py` | 现有会话镜像工具，保留原位置供启动脚本使用 |
| `mcp-tui/` | 旧 MCP 终端接入工具；不与当前 npm 终端入口混用 |
| `archive/` | 已归档的临时捕获、重启备份脚本，保留原文，不视作当前可重放流程 |

整理前工具说明完整保存在 [历史工具 README](../docs/history/tools-README-整理前-20261028.md)。其中旧机器路径与“广播四方”方式不作为当前验收要求。
