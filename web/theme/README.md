# 夜间控制台 / Night Console — 颜色系统说明

> 这套文件只做一件事：把「多智能体群聊 · 统一窗口」的 74 个散装色值，收敛成一套可解释、可维护、可校验的深色系统。
> 改动全部落在颜色层，不动任何布局：`display / width / height / flex / gap / margin / padding / z-index` 一律原样。

## 一、为什么是这套配色

原界面的问题是**同明度平面**：画布、侧栏、气泡、输入框挤在同一个黑度里，只有「用户气泡」那一块饱和蓝在发光。读者的眼睛没有落点，只能靠 1px 灰线猜层级。

这套系统的解法是两件事：

1. **用亮度分层，不用边框分层。** 五级表面（canvas → sunken → surface → raised → overlay），每级差 4–7 点明度，边线只做「收口」不做「划界」。
2. **把饱和色收押成三种语义。** 一屏之内只允许出现三类彩色：
   - 冰蓝 `--nc-ice`：**能点的东西**（按钮、链接、焦点、选中）
   - 金 `--nc-gold`：**没做完、需要你看一眼**（进行中、暂停、等依赖、星标、高亮）
   - 身份色：**谁在说话**（只做 2px 左条 + 名字，不铺满）
   绿 = 完成/在线，红 = 真失败。橙色只留给终端命令行那种极小面积。

> 一句话记法：**颜色记账，不记账情绪。** 每个彩色出现都要能回答「它替我说了哪句话」。

## 二、表面阶梯

| 层 | Token | 值 | 用在哪 |
|---|---|---|---|
| 0 画布 | `--nc-canvas` | `#0b0e13` | 聊天流 `#log`、工作台 `#workbenchPanel`、活动栏 |
| 1 下沉 | `--nc-sunken` | `#0e131a` | 输入框、`pre`、思维链 `.thinkbox`、步骤详情 `.detail` |
| 2 表面 | `--nc-surface` | `#131821` | 侧栏、`header`、`#workbenchBar`、`#composer` |
| 3 抬起 | `--nc-raised` | `#19202b` | 消息气泡、成员卡、`.wb-card`、`.box` |
| 4 浮层 | `--nc-overlay` | `#202835` | 弹窗、浮动菜单、选区浮条 |

**硬规则**：同一层级的容器必须同色同边。`header` 与 `#workbenchBar` 必须同面，`#log` 与 `#workbenchPanel` 必须同面——否则切换视图会「闪一下」。

## 三、文字四级

| 级 | Token | 最低对比度 | 用途 |
|---|---|---|---|
| 正文 | `--nc-text` `#e8edf5` | 13.9:1（最亮表面） | 消息正文、标题 |
| 次要 | `--nc-text-2` `#a7b3c6` | 6.3:1 | 元信息、按钮字、说明 |
| 三级 | `--nc-text-3` `#8f9db3` | 4.85:1 | 最小注释、耗时、`small` |
| 禁用 | `--nc-text-4` `#5e6a7c` | 2.4:1 | **只准用于禁用态**，不承载信息 |

## 四、身份色（谁在说话）

`--id-user #7f9df5` · `--id-claude #e08a6b` · `--id-codex #3fc79a` · `--id-model #58c6e8` · `--id-dsh #6e9bff` · `--id-codebuddy #9a8dff` · `--id-mirror #96a1b4`

同一明度、控制饱和，只靠色相区分（色轮 18° / 160° / 186° / 222° / 245° / 285° + 中性）。
**身份色只出现在两处**：气泡左侧 2px 竖条、说话人名字。它不参与背景、不参与按钮。

## 五、文件分工与层叠顺序

```
00-tokens.css      token + 全局基座（选择色、焦点环、滚动条、环境光）
10-shell.css       活动栏 / 侧栏 / 成员卡 / 状态栏 / 拖拽遮罩
20-chat.css        主区 / 消息流 / 思维链 / 步骤流 / 输入区 / 弹窗
30-workbench.css   工作台工具栏 / 卡片 / 任务块 / 工作台对话框
```

`index.html` 在 `</style>` 之后按 00→10→20→30 顺序 `<link>`，靠**加载顺序**压过内联样式，全程不用 `!important`。
`hub.py` 为此加了一条只读路由：`/assets/theme/<name>.css`（`basename` 收敛，防目录穿越）。

## 五点五、浏览器要求

判定标准用到 `color-mix()`（19 处透明叠加）与 `:has()`（任务块状态竖线），两者都要求 **Chromium 111+**。
本项目的界面跑在本机 Edge，远高于此；若将来要在老内核里打开，需要为 `color-mix` 补静态 rgba 回退。

遮罩统一走两个 token：`--nc-scrim`（弹窗、`::backdrop`）、`--nc-scrim-2`（全屏拖拽层），不要再写字面值。

## 六、自检方法

```bash
# 预览（把 /assets 映射到 web/，与线上同构）
python _preview/serve.py            # http://127.0.0.1:8781/_preview/index.html
# 状态：?state=chat&panel=conv|agents|health|share|filter / dialog / wb / empty
```

改色后必须做两件事：
1. **量对比度**，不要凭眼睛。`_preview/png.py` 可读像素：`read_png()` + `pixel()`。
2. **看三层是否分得开**：截图缩到 30% 看整体，放大到 200% 看发丝线。

## 七、别做的事

- 别用纯黑 `#000` 当画布：OLED 上边界会消失，改用 `#0b0e13`。
- 别给选中态加外发光（`box-shadow: 0 0 0 1px` 之外的光晕）：深色底上会糊成一团。用「描边 + 6% 底」。
- 别让两个彩色抢同一件事：一屏只能有一个实心主色按钮。
- 别把身份色铺到背景上：五个气泡各染一片色，界面立刻变成调色盘。
